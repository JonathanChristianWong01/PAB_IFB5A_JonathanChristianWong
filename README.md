## Judul Proyek
Game Quiz Jaringan Komputer

## Deskripsi
Aplikasi Game Quiz Jaringan Komputer adalah aplikasi Android yang dirancang untuk menguji dan meningkatkan pemahaman mahasiswa terhadap materi jaringan komputer.

## Teknologi/Framework
- Kotlin
- Android Studio
- Jetpack Compose
- Gradle
- Git & GitHub

## Fitur Utama Saat Ini
- 4 kategori soal (Dasar, Protokol, Perangkat, Campuran)
- 30+ bank soal pilihan ganda
- Timer 30 detik per soal dengan indikator peringatan
- Sistem skor +10 poin per jawaban benar
- Lifeline bantuan 50:50
- Progress bar & review jawaban di akhir
- Tampilan mobile-friendly / responsive
